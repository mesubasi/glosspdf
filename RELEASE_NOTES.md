# GlossPDF v1.0.0 – Initial Public Release 📄✨

> **Sleek, modern, and open-source desktop PDF workstation.**  
> *A bloat-free, local-first, privacy-respecting desktop application built with Electron 29, React 18, and TypeScript.*

---

## 🌟 What's New in v1.0.0

GlossPDF is designed from the ground up to deliver a clean, fast, and independent desktop experience adhering to the official **ISO 32000** PDF standard.

### 📖 High-Performance Viewing & Navigation
- **Virtual Page Rendering:** Fast scrolling through large documents with minimal memory footprint.
- **Precision Zoom Engine:** 15 discrete zoom steps from **8.33% up to 800%**, plus instant **Fit Page** and **Fit Width** modes.
- **Multi-Tab Interface:** Work on multiple PDF documents seamlessly.
- **Thumbnails & Bookmarks:** Quick navigation with visual page thumbnails and hierarchical bookmarks outline.
- **Full-Text Search:** In-document keyword search with match counting and highlighting (`Ctrl+F`).

### ✏️ ISO 32000 Annotations & Markups
- **Text Markups:** Highlight, underline, and strikeout with precise bounding box detection.
- **Sticky Notes / Comments:** Place expandable comment pins anywhere on pages; manage all notes via the sidebar.
- **Freehand Pen (Ink):** Smooth vector ink drawing.
- **Shapes & Text Boxes:** Draw rectangles or add standalone text boxes.
- **Undo / Redo:** Full history tracking for all annotation actions (`Ctrl+Z` / `Ctrl+Y`).
- **Standard Compliant:** Annotations are saved as native ISO 32000 `/Highlight`, `/Underline`, `/StrikeOut`, `/Text`, and `/Ink` dictionaries readable by any compliant PDF viewer.

### 📑 Page Organization, Merge & Split
- **Organize Pages Grid:** Visual thumbnail grid to reorder pages via drag-and-drop or arrows, rotate 90° clockwise/counter-clockwise, delete pages, or insert blank pages.
- **Merge PDFs:** Combine multiple PDF documents into a unified file with customizable ordering.
- **Split PDF:** Extract all pages individually or split by custom page ranges (e.g., `1-3, 4-8`).

### 🖋️ Signatures, Stamps & Watermarks
- **Handwritten Signatures:** Interactive canvas to draw wet signatures and place them anywhere on your documents.
- **Official Stamps:** Predefined stamps (*APPROVED*, *CONFIDENTIAL*, *DRAFT*, *REJECTED*) with automated dates.
- **Diagonal Watermarks:** Semi-transparent customizable text watermarks.

### 🖼️ Image Insertion & Page Export
- **Insert Images:** Embed PNG or JPEG images onto any page with custom scaling and anchor positioning.
- **Export Pages as Images:** Render any page or complete documents as high-resolution PNG or JPEG files.

### 🔒 Security & Compression
- **AES-256 PDF Encryption:** Password-protect documents using industry-standard ISO 32000 AES-256 encryption.
- **PDF Compression & Optimization:** Purge redundant metadata, rebuild cross-reference tables, and optimize object streams to reduce file size.

### 🛡️ Privacy & System Language
- **100% Local-First:** All processing happens entirely on your machine. Zero cloud dependency, zero telemetry.
- **Automatic Language Detection:** Automatically matches your operating system language (English / Turkish) with single-click manual toggle.
